# LNG Safety Valve AI Monitoring System

## 项目定位
本项目是一个面向 LNG 储罐安全阀的工业智能预警系统，当前版本聚焦“专利核心版”能力建设。

系统不是单纯展示 Isolation Forest 的异常检测结果，而是构建了一套更适合申报专利和参加创新大赛的方法链：

- 机理健康指数建模
- 滚动自适应历史基线
- 时序退化特征识别
- 异常共识与分层风险升级
- 告警闭环与管理摘要输出

核心方法名称：

`一种基于自适应健康指数与分层异常共识的LNG储罐安全阀智能预警方法`

## 当前能力
- 双站点分角色登录：华盘站、罗所站、领导
- 站点级数据隔离与领导只读查看
- 3线压力趋势图、HI 热力图、阀门 HI 对比
- 规则风险、AI异常、退化异常、最终共识风险同屏对照
- 告警闭环流转：待确认 -> 已派工 -> 处理中 -> 已验证 -> 已关闭
- 比赛摘要、管理摘要、专利交底书提纲导出
- 本地 CSV 与 Supabase 双存储兼容

## AI 方法链
系统当前采用 4 层方法链：

1. 机理健康层  
基于压力接近整定值、近3日斜率、动作、微放散、温度液位耦合，形成基础 HI 与规则风险。

2. 自适应基线层  
按 `station + valve_type` 建立滚动历史基线，输出相对本站本阀历史的偏离程度。

3. 时序退化层  
识别连续上升、持续接近整定值、短时突增、波动放大、活动异常等退化迹象。

4. 异常共识层  
融合规则风险、Isolation Forest、历史基线偏离、退化分和持续性，给出 `AI观察 / AI升级 / AI高风险`。

## 项目结构
- [psv_app.py](./psv_app.py)：Streamlit 应用入口与页面编排
- [data_pipeline.py](./data_pipeline.py)：数据标准化、站点隔离、告警与审计
- [risk_engine.py](./risk_engine.py)：机理健康分与领域特征
- [ai_engine.py](./ai_engine.py)：基线、退化、异常共识、案例回放
- [reporting.py](./reporting.py)：管理摘要、比赛摘要、专利交底书提纲
- `tests/`：最小测试集

## 运行方式
本地运行：

```bash
streamlit run psv_app.py
```

如需启用云端数据：

- 配置 `SUPABASE_URL`
- 配置 `SUPABASE_KEY`
- 在 Supabase 中执行 [supabase_schema.sql](./supabase_schema.sql)

## 测试
```bash
py -3 -m unittest discover -s tests -v
```

建议在答辩或交底书中突出以下 5 个创新点：

1. 面向 LNG 安全阀的机理健康指数构建方法
2. 基于站点-阀门分组的滚动自适应历史基线
3. 结合孤立森林与时序退化特征的双引擎异常识别
