Step 1：在本地改代码

比如改 psv_app.py

Step 2：本地运行测试
streamlit run psv_app.py


确认功能OK、没报错

Step 3：提交到 GitHub

在项目文件夹里：

git add .
git commit -m "更新：xxx功能"
git push

Step 4：Streamlit Cloud 自动更新

通常 1-2 分钟内自动重建部署

Step 5：刷新云端链接验证

打开你给同事的那个网址，看功能是否上线

✅ 只要你 “git push” 了，云端就会跟着更新
❌ 你只改了本地、不 push，云端不会变

🔥 你最容易混的点：本地环境 vs 云端环境
本地运行用：

.streamlit/secrets.toml（如果你本地配过）

云端运行用：

Streamlit Cloud 的 Secrets（网页里配置）

它俩互不影响。

Supabase 会不会受影响？

更新功能一般不会影响 Supabase 数据（因为数据在 Supabase 云里）。

但如果你改了数据库结构（新增字段/改表名），那就需要同步改 Supabase 的表。

✅ 常见情况：你只改页面、改图表、改逻辑
👉 完全不用动 Supabase

⚠️ 只有这种情况才需要动 Supabase：

你新增一个录入字段（比如“备注 remark”）

或者表名、字段名改了

那我也可以教你怎么改表结构（很简单）。
